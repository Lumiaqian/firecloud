WeatherStage 是从已批准画笺提取的环境天气与固定纸笺参考，天气过场不改写所选预报事件。

# WeatherStage

## 来源

- `designs/paper-place-finder/project/SkyLetterStudy.dc.html`：11–21、40–51 行，九种天气、四种天色、雨雪雹粒子、云雾、固定月位与纸缘接触。
- `SkyMotionFlow.dc.html` 与 `SkyMotionFlowMobile.dc.html`：650 ms 透明度过场与局部反馈；当前契约将黄铜夹 / 闪电放在时间纸、风接触 / 自由纸角放在天气批注，评分仅圈注 / 等级。
- `designs/paper-place-finder/project/canvas.json`：`notes.approvedTypography`、`notes.motionCoverage`、`notes.sceneContract`、`notes.forecastCoverage`；以当前方向和不透明纸面为准，不采纳历史备选。

## 使用 / 避免

用于区分「当前环境」与「预报日期」的设计交接、桌面/手机构图和减弱动态讨论。使用不透明 `.sl-paper`，正文固定在天气之上；所有操作区域至少 44 px，朱砂选中与墨色虚线焦点不是同一状态。

预览视口不宽于 700px 时，评分先读、时间靠右；701–900px 为 440px / 270px，宽屏 480px / 300px。三张纸从 `components/card-foundation.css` 取材质、字号与内部几何，bundle.css 仅定位和播放环境，不另存天气专用卡片。天气批注也按同一两组分项模式显示，不用两按钮面板冒充完整七日。

不要把天空渐变当作数据读取底色，不让降水穿透纸面，不让夹口或整张纸随风漂移，不让雷暴自动闪烁数据，不把未来预报当成当前天空。不要复制本卡作为生产天气引擎或权限处理器。

## 消费方输入与关键状态

参考输入：`weather` = `clear | partly | overcast | fog | rain | snow | thunder | hail | wind`；`light` = `day | dawn | dusk | night`；动效意愿与系统 `prefers-reduced-motion`。环境展示层只读这些输入。正式应用提供真实天气/昼夜状态；卡片只提供确定性本地样例，无 API、网络、定位、相机、浏览器存储或持久化组件状态。

- 晴空 / 多云：固定日轮；夜色保留固定弯月。月轮仅为源稿固定图示，不声称是真实天体位置。
- 阴 / 雨 / 雷雨 / 冰雹：云幕置于月轮之前；雨雪雹置于纸面之后。
- 雨：上缘水滴；雪：源稿折线积雪；冰雹：上缘局部弹跳；风：少量淡铅笔风痕 / 纤维与偶发灰绿叶片从天空掠过，天气批注自由角微动，纸与胶带锚点不漂移。不使用花瓣和彩纸。
- 时间纸黄铜夹点击：单次650 ms局部引雷；评分圈注 / 等级暖光3600 ms。风天气160 ms后起轻档调度、之后每7.2 s一批，最多5条、每条3000 ms；天气批注胶带点击强档最多10条、每条2400 ms。每条另加0–350 ms随机时长，第k条延迟 `120 + k × 50` ms（k从0计，错峰跨度最多450 ms），强档纸缘状态3350 ms后回落。轻档纸角峰值−3 px / −2°、胶带−5°；强档纸角−6 px / −4°、胶带−9°。横向行程随视口 / 舞台宽度变化，纵向弯折、正反向不同转速、末段22%淡出；每三批至多一片叶。活动载体上限18，重复点击只追加空余名额并延长纸缘状态，不清空、重启或截断已有一轮。
- 键盘触发仅给「键盘操作仅文字反馈」，不播放本次手动装饰，也不清除已有环境阵风、降水与星光。关闭动效 / 系统减弱动态 / 页面隐藏：清理未完成粒子、纸缘计时及环境阵风调度，停止柔光变化、闪电、月晕、星光和纸角，恢复不补播；保留静态月轮、云雾、天气名称和纸缘状态。切换天气或天色同样清理旧阵风，再按新环境调度。动效关闭时只显示「动效已关闭」，不宣称已播放引雷或阵风。夜间降水中的星光与其他夜空同样缓慢闪烁。
- 日期演示：03 / 05 日按钮只更新横笺选中态，主笺 77、17:12 与环境完全不变。完整的预报事件联动由 Forecast 参考负责，本卡明确不是该行为适配器。

## 主题与实现边界

预览初始跟随父级 `<html data-theme>` 的四种主题；手动选择天色后只覆盖本卡，不修改 html 或 body。纸张与墨色继续消费共享主题 tokens。天气渐变消费 `--weather-<preset>-top/mid/bottom`，不声明根级默认 token。粒子、云雾、纸角等源稿插画色保留在 `components/bundle.css`，它们是插画几何用色而非语义 token。

本卡为原生 HTML/CSS/JS 预览初始化器，不依赖 React。36个预置天气 / 天色画层通过650 ms opacity transition交叠，连续切换从当前透明度转向，非活动画层暂停动画；风痕使用独立天空装饰层，纸面、数值与正文不参与运动。这些是代码设计，不是本轮运行验收结果。本轮没有浏览器、设备、能耗或天气边界测试。未模拟独立雨风轻 / 强控制、右划天空手势和完整七日联动；日期按钮仅改两项选择标记，评分、时刻和固定批注不重算。对应运动规则见 Motion.md，不将设计预览限制冒充生产能力缺失或已验证声明。
