FactorGrid 用云层与空气两组旁批，解释所选预测的数值、增减分及主要影响项。

## 来源
来源为 `SkyLetterStudy.dc.html`、`SkyLetterMobile.dc.html` 与 `home-card-composition.css` 的已采用 A；边界取自 `SkyForecastEdgesMobile.dc.html`。组标题铅笔划线、侧边括注、重点值划线与曲线旁批共用原始资产。

## 使用与避免
放在主指数之后、未来七日之前。桌面两组并排，手机两组纵向；每组内部是一列标签—数值—增减分，非四列仪表网格。数值与单位独立，关注项划线，有利项保留「+」；主要扣分旁批跟随实际数据，缺测时不作判断。

## 消费输入与关键状态
消费者提供标签、显示数值、单位、有符号分项变化、理想区间、说明、基准、封顶说明、日期/事件与更新时间。常规样例：高云 32% / −4、中云 25% / −1.6、本地低云 18% / −2.3、太阳方向低云 40% / −10、湿度 55% / 0、能见度 32 km / +6、AOD 0.18 / 0、PM2.5 18 μg/m³ / 0。这些是源画布的显示值，不应用显示后数值反推总分。

「封顶」例保留 10 分上限解释，AOD / PM2.5 与生产一致显示「— 缺测」，计分变化标为「—」，辅助说明为「缺测，模型沿用默认值」，不把模型默认项当作实测。必要分层云量缺失时整份评分为「—」，不以零值替代。details 用原生 summary 展开，切换样例保留展开状态。

## 本地预览边界
原生 HTML/CSS/JS「非实时样例」，不计算指数、不联网。样式来自 bundle.css，共享 paper/ink 字色与 brace/pencil/leader 资产。

单位可换至下一行但不拆开自身。44px 展开目标、独立虚线焦点与至少 12px 页脚适用于四种环境主题。
