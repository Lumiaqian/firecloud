PaperNote 用开口圈注的评分笺与右上方事件便笺，呈现同一次晨昏观测的判断和时间窗口。

## 来源
- `SkyLetterStudy.dc.html` 与 `home-card-composition.css`：软纸面、开口圈线、等级引线、建议括注；桌面主笺 480px、事件笺 300px。组件预览按容器采用 440px / 290px，保留相同相对排版。
- `SkyLetterMobile.dc.html`：主笺占可用宽度、时间笺靠右；分数上限 99px，不能把整张桌面图缩成手机图。
- `SkyForecastEdgesMobile.dc.html`：封顶与必要云层缺失的同构呈现。

## 使用与避免
用于所选日期、时段的主要研判。圈线包住数字但保持开口，引线指向等级，建议放在括注之后；无需独立印章。时间、窗口、峰值分层，当前实况不跟随所选日变化。两张纸各自标清预报日期，已保存记录只展示静态「预报时刻」，不显示旧记录的实时倒计时或「观赏中」。

评分与时间笺必须和 FactorGrid、ForecastStrip 使用同一 `supporting-paper-mask.svg`、`paper-grain-wide.png` 及 `drop-shadow(1px 5px 6px #43352b12)`，不再用 `border-radius` 或圆角 inset 构造独立卡面。`score-annotations.png` 与 `home-time-marks.png` 只负责圈注与笔迹；评分插画同样裁到纸面内。装饰与文字分层，数字、单位、等级、建议保持可选中和可编辑；天气接触只在纸缘。

## 消费输入与状态
消费者提供指数、等级、事件时刻、时区/方位、窗口、峰值、建议、日期与更新时间。必要云层缺失时显示「— / 暂不可用」，不造出 0 分。封顶样例为 8 分、上限 10 分；常规样例为 77 分。三个按钮只切换冻结源样例，不重算算法。

已有记录的 cached / stale / refreshing / switching 由 StatusNote 在城市下提供同一紧凑状态行，不在两笺上方增加第三张大纸。更新时间带日期，刷新/切换只原位更换状态与动作，两笺的尺寸、位置和原记录日期保持不变。未确认的目标日期、时段或城市不可提前写到旧记录上；换城无目标城市记录时不借用旧城分数。新鲜度不在每笺反复警告，旧天气也不称为当前实况。

## 本地预览边界
原生 HTML/CSS/JS 设计参考，非 API 适配器或持久化生产组件；预览均标注「非实时样例」，不含评分算法、网络或实时倒计时。共享 bundle.js 初始化样例交互，bundle.css 与已上传圈注资产负责构图。

桌面保留分数左下、事件右上；窄屏依批准手机稿分数在前、事件靠右，不能上下贴成同宽通知卡。时间字号对应 `sl-time58` / `sl-time54`，组件 CSS 保留源稿相同值以支持预览渲染。控制最小 44px，虚线焦点与朱笔选中分别表达键盘位置和当前样例。
