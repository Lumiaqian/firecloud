ForecastStrip 是无折痕的连续七日横笺，用日期按钮、圈注最高日与选中划线呈现预报展望。

## 来源
来源为 `SkyLetterStudy.dc.html`、`SkyLetterMobile.dc.html` 和 `home-card-composition.css` 的已采用 A。桌面纸宽至少 900px；手机 7×125px 加内边距为 915px。软纸边不切成七片，也没有折痕渐变。

## 使用与避免
可用日期为 button，当前项用朱笔划线与「当前」，最高日独立开口圈注；两种状态可落在同一天。焦点为独立虚线。仅条内横滚，不撑宽页面。第五至七日保留「远期 / 仅供参考」，无事件和必要资料缺失不记零分。

## 消费输入与关键状态
输入七日日期/星期、冻结指数/等级、事件时刻、可用性及原因、远期标记、所选日期和所选日摘要。常规样例七日均可选；封顶样例首日 8 分、周四 95 分；边界样例 06 日无对应事件、08 日分层云量暂缺，禁用对应按钮并明确「—」。缺测样例首日也不可研判。切换样例保留所选日期，必要时摘要解释缺测；最高日动作定位 05 周四并更新同一摘要。无数据日期不是可执行动作。

## 本地预览边界
原生 HTML/CSS/JS 设计参考，非 API / 持久化生产组件。所有数据为「非实时样例」，取自批准源稿渲染输出；预览只选择固定数据，既不重算评分也不请求天气。最高日为源样例固定周四，不提供通用推荐算法。

纸面、七日内部排版和笔迹由 `components/card-foundation.css` 唯一定义，`bundle.css` 只保留横滚容器、标题、摘要与样例控件。使用 paper、ink、font-hand 及原始 pencil / outlook-focus 图片，不使用折痕色带。摘要 polite 通知，操作后保留焦点；页脚至少 12px。真实按钮用 `aria-pressed`，导航样例用 `aria-current="page"`，静态不可操作样本用 `data-current="true"`；后者不能代替真实控件语义。本轮未运行横滚、焦点、读屏或视口验收。
