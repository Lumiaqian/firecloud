地点行把切换地点与切换收藏分为两个独立原生按钮，用“当前”文字和细下划线表示当前地点。

## 来源与原值

- `designs/paper-place-finder/project/SkyPlaces.dc.html` 第 12、48 行，以及 `SkyPlacesMobile.dc.html` 第 12、48 行：收藏地点的编号、地名、详情、当前标记与独立星标结构。
- `components/bundle.css` 保留行最小高度 `67px`、桌面行间距 `8px`／移动 `6px`；地名按钮内边距 `9px 0`，桌面内部间距 `15px`／移动 `11px`。桌面地名 `21px`／移动 `20px`；编号、详情、当前标记 `12px`；星标 SVG 桌面 `21px`／移动 `20px`，线宽 `1.5px`。
- 当前地点用 `aria-current="location"`，地名下划线 `1px`、偏移 `6px`、`--ink-accent`。星标的原 SVG 路径直接复制；收藏填色沿用 `#a638272b`，通过系统 token `--ink-accent-wash` 引用。

## 使用与避免

用于显示地点集合中的当前项，以及每项独立的收藏开关。点击地名才切换地点，星标只改收藏；不得把整个行包成一个按钮，也不得把星标嵌套进地名按钮。当前标记不铺色块，不用收藏星标暗示当前地点。

键盘 Tab 分别到达地名与星标；Enter／空格分别执行对应动作。选择后的细实线与焦点虚线／图标焦点圈相互独立；“当前”文字避免仅靠颜色识别。不为普通按钮组加入未实现的列表框方向键协议。

## 消费者输入与状态

此处为 HTML/CSS 模式，没有导出的组件函数。消费者提供稳定地点标识、名称、详情、编号、唯一当前地点、每项收藏布尔值，以及彼此独立的选地点／切收藏处理器。当前项设 `aria-current="location"`，非当前项移除该属性；星标提供 `aria-pressed` 和随状态变化的“收藏某城市／取消收藏某城市”可访问名称。

关键状态：当前／非当前、收藏／未收藏、文字焦点／图标焦点、激活、悬停。地名按钮伸展、星标保留至少 `44 × 44px` 点击区域，详情允许换行。减少动态时无动画；强制颜色模式保留系统焦点和当前项下划线。

## 本地预览边界

`preview.html` 是非实时、纯本页内存样例，不是 API 或持久化生产组件。取消收藏后特意保留样例行，方便再次切换并观察收藏独立性；这不是生产收藏列表的移除、撤销或容量协议。当前地点只影响卡内标记与反馈，不触发天气加载。全部临时数据刷新即复原，不联网、不定位、不读写存储。共享 token 和 CSS 由运行时预载。
