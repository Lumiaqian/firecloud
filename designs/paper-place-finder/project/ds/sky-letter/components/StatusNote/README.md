# StatusNote

StatusNote 在城市下用紧凑文字行说明已有记录的新鲜度，保留评分与时间两张纸；仅无记录时使用独立状态纸。

## 来源
`SkyCached.dc.html` / `SkyCachedMobile.dc.html` 是保留记录的主要层级参考：城市、带日期的上次更新时间与原位更新动作、错落双纸、待更新天气。无记录状态沿用 `SkyFeedbackMobile.dc.html`、`SkyLoadingMobile.dc.html`、`SkyEmptyMobile.dc.html`、`SkyMissingMobile.dc.html` 的软纸、标题铅笔线与侧括注。预览保留既有杭州 11/03 晚霞 77 分、17:12 日落、16:57–17:37 窗口及 11/03 15:30 更新时间样例；这些不是实时结果。

## 使用与避免
先区分有无可用记录。已有记录的 cached / stale / refreshing / switching 共用城市下同一文字行，不增加第三张状态大纸、不清空双纸，也不因动作而推移卡片。仅无记录的 loading / error / empty / missing 使用专用状态纸，不展示虚构的分数、窗口或保留记录。获取失败不是恶劣天气或 0 分。

## 消费输入与关键状态
输入当前状态、当前城市、请求的日期/时段、原记录的城市/日期/时段、原记录的实际更新时间与重试意图。更新时间必须含日期；请求目标与展示中的记录分别标明，不能提前改写旧卡日期。
- loading：首次读取，没有可用手记，不显示指数或时间窗口。
- error：首次失败、无可用预测；「重新尝试」只进入 loading。
- empty：极昼/极夜无对应事件，不制造事件时刻或零分。
- missing：必要高空分层云量缺失，不研判、不显示可靠指数。
- cached：恢复保存的预报，状态行写「尚未更新」，显示上次更新日期/时间；只提供静态事件时刻和窗口。
- stale：更新未成功，状态行一次说明「更新未成功 · 沿用记录」。原始预报日期、指数与窗口保持不变，不在每张纸重复警告。
- refreshing：同一行改为「正在更新…」，动作真实 disabled / aria-busy；新内容未到前不清空、不提前替换。刷新不会让保存记录自动成为当前数据。
- switching：本地示例请求 11/04 朝霞，状态行标明「11/04 朝霞读取中 · 暂留晚霞」；两张纸仍标 11/03 晚霞。若换城市且没有目标城市记录，应采用无记录读取状态，不能把旧城分数贴到新城标题下。

状态行始终两层：上次更新日期/时间、简短状态；右侧动作保留相同占位。刷新或切换仅原位替换文字与动作，不影响双纸位置。宽屏评分左下、时间右上；900px 及以下按评分在前、时间靠右的纵向顺序排列，组件预览的中等宽度也不得溢出。

## 新鲜度与时间
保存、过期、未确认记录没有实时倒计时，也不显示「观赏中」等正在发生的判断。时间笺使用「预报时刻」，两笺分别带记录日期，评分笺页脚只写「保存的预报 · UTC+8」。旧天气不冒充实况；双纸下只写「天气实况待更新」。完整新鲜度说明集中在状态行，避免反复添加「过时 / 非当前」噪声。

## 本地预览边界
原生 HTML/CSS/JS 初始化器 `window.SkyLetter.StatusNote(document)`，不是 React 组件、API / 缓存适配器或持久化生产组件。顶部八个按钮只切换「非实时样例」。cached 的「刷新」和 stale 的「重试」只进入 refreshing；无记录的「重新尝试」只进入 loading。没有网络、存储、计时器、随机结果或自动成功，通过顶部按钮手动选择其他状态。

原记录 DOM 在四种保留态之间不重建；读屏由单一 polite live region 告知状态。动作转入 disabled 或无记录纸被收起时，将焦点移到对应顶部状态按钮，避免焦点遗失。加载图形静止；减少动态偏好及强制色模式均可使用。样式由 `components/bundle.css` 复用 paper/ink/space tokens 与现有圈注、时间笔迹、铅笔线、侧括号素材；不添加边框、印章或新主题。
