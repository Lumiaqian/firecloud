## 使用与避免

用于搜索城市；必须有可见 label，不以 placeholder 替代标签。搜索框并非 ARIA combobox：结果是独立原生按钮，Tab 可逐项到达，Enter／空格可选择。不要添加并未实现的 listbox 或方向键语义。

清空按钮始终保留位置，空查询时 disabled；输入焦点不改变边框厚度或内边距，因此没有焦点布局跳动。无匹配时仍保留查询、清空按钮及当前地点，不清除旧选择。不加入定位模拟、网络加载、搜索失败或天气读取行为。

## 消费者输入与状态

这是原生 HTML/CSS 参考模式，没有组件 JS 包。消费者提供唯一输入 id、关联 label、提示 id、查询值、候选城市名称／详情／匹配词、过滤与选择处理器、结果计数和空结果状态。示例允许中文城市／省份和示例拼音子串；不是地名检索服务，不承诺生产搜索的匹配策略。

关键状态：初始空查询、输入焦点、已有查询与可清空、匹配列表、无结果、城市已选。结果计数和选择反馈分别使用 polite 状态播报。搜索输入高至少 `49px`，清空与结果按钮点击区域至少 `44 × 44px`。强制颜色模式保留系统焦点轮廓；本模式无动态。

### 夜间占位文字的明确修正

保留源 token `--ink-placeholder: #6f685c`，但夜间纸色 `#e7e4d6` 上的对比度约 `4.32:1`，未达到普通文字 `4.5:1`。因此仅预览 CSS `[data-theme="night"] .sl-city-input::placeholder` 使用 `--ink-muted: #625b4e`（约 `5.27:1`）。其余时段继续使用来源占位色；这是可访问性修正，不是新增视觉主题。
