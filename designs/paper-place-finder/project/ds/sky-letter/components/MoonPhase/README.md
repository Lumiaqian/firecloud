# MoonPhase

## 来源

- `designs/paper-place-finder/project/SkyMoonMobile.dc.html`：10–12 行布局与呼吸时序，18 行 SVG 月盘/亮面裁切/坑纹/地平线，30–42 行七组固定样例与预报上下文。
- `designs/paper-place-finder/project/SkyLetterStudy.dc.html`：40–51 行四种天色与固定月位原则；本卡将批准的天空 palette 与批准的月相札记组合，不新增天文规则。
- `designs/paper-place-finder/project/canvas.json`：`notes.flowCoverage`、`notes.sceneContract`，此刻月相独立于未来预报，月位不作装饰漂移。

## 使用 / 避免

用于讨论「月相亮面」与「可见性」的区别、夜巡信息层级，以及上弦/下弦和蛾眉/残月的左右方向。所有月面 SVG 路径与裁切逐字来自批准稿；文字明确为「月相示意 · 非天空位置」。

不要用固定图示代替天空坐标，不凭照亮比例反推出月龄、农历或仰角，不把满月当成永远可见，不在新月画出亮面，不在 `below` 状态把月轮挂在天空中。月轮不平移、不摇摆、不旋转；只有月晕和星光缓慢改变透明度。

## 消费方输入与关键状态

消费方提供真实的月相/照亮比例/可见性与说明文本；正式天文结果应来自现有计算来源。本地选择器仅查表，绝不进行历算或请求真实天文数据。

- `crescent`：蛾眉月，右侧 12% 亮面；源稿月龄样例 3.3 天。
- `quarter`：上弦月，右半面 50%。
- `full`：100% 完整亮面。
- `new`：源稿退化路径 `M100 12 Z`，0% 亮面；保留暗圆示意，移除月晕。不要向太阳附近寻月。
- `below`：保留上弦月的相位资料与原路径，但隐藏整个月轮，显示原稿地平线下标记；仰角样例 −8.4°。
- `waning`：下弦月，左半面 50%。
- `waning-crescent`：残月，左侧 12% 亮面。

所有比例、月龄、农历、距角、仰角、方位、样例时间与建议均来自 `SkyMoonMobile` 固定 presets，标注非实时、不作天文历算依据。更换相位同时更新 SVG、裁切、可访问名称和札记；更换预报日期只更新预报上下文，绝不改变月相、观测时间或环境天色。

## 主题、动态与限制

父级 `data-theme` 支持 day/dawn/dusk/night，初始跟随；本地天色选择只改变本卡。纸笺/墨色使用共享 tokens，月面使用 `--moon-dark`、`--moon-outline`、`--moon-lit`、`--moon-crater`。月晕等源稿透明插画用色不充当语义 token。日间仍可显示月相示意，并不声称该相位此刻在白昼可见。

月晕 12 s、星光 7 s；关闭动效或系统减弱动态时均静止，月相与天气/状态文字仍保留。强制颜色模式隐藏光晕和星点，保留系统色明暗轮廓、地平线标记及焦点。

这是局部原生 HTML/CSS/JS 的交互设计样例，不是 API 组件、持久化控件或生产天文适配器。无网络、相机、定位或存储。未复制整页返回/关闭札记导航，因为本卡只呈现月相参考，不替代应用路由。详见 `Motion.md`。
