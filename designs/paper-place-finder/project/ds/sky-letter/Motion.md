# 动效与环境契约

天空可以流动，纸上信息留在原处。本规范从批准画板提取，不重写生产天气、预报或天文引擎；所有预览均为非实时本地样例，无网络、相机、定位权限与持久化。

## 依据与优先级

1. `designs/paper-place-finder/project/canvas.json` 的当前方向说明、`notes.sceneContract` 与 `notes.motionCoverage` 是分层、静态保留与阅读稳定性的边界；历史备选不作为依据。
2. `SkyLetterStudy.dc.html`（11–21、40–51 行）决定九种天气、四种天色、纸缘雨雪雹风与固定月轮；`SkyMoonMobile.dc.html`（10–12、18、30–42 行）决定月相路径、可见性与月相札记。
3. `SkyMotionFlow.dc.html` / `SkyMotionFlowMobile.dc.html`（12–18、43–49 行）决定可中断的 650 ms 过场和手动局部反馈。桌面/手机遵循同一行为契约，不另建移动端动效方向。
4. 当前分层手绘阵风覆盖旧稿的细划痕、碎屑、固定行程与重启策略：主风带使用2–3根不等长开口弧线、间断复描及局部回卷尾端，配短风丝与偶发带叶脉翻面叶片；不增加同样短线，不使用花瓣、彩纸、发光或模糊粒子。其余天气和业务状态不改。

优先级为：**阅读与可访问性 > 真实环境状态 > 所选预报事件 > 纸缘装饰互动**。系统减弱动态覆盖本地「动效开」；静态反馈仍需可辨识。任何动画都不得改变评分、日落/日出时间、观赏窗口或文字的可信含义。

## 三个互不改写的状态域

| 域 | 来源 / 职责 | 不允许的副作用 |
| --- | --- | --- |
| 当前环境 | 当前地点的天气、昼夜、太阳/月亮位置、月相、降水、风速；设计卡仅使用批准 presets | 不跟随预报日期/朝晚霞标签自动切换；不凭样例坐标声称实时天空位置 |
| 所选预报事件 | 预报日期、朝霞/晚霞/日轮视角及该事件分数、时间、窗口、批注、七日最高 | 不改写当前天气、天色或此刻月相；缺测不记零分 |
| 纸面接触 | 环境派生的上缘水滴、积雪、雹粒弹跳，以及夹子/圈注/胶带尾和风下真实纸面的手动反馈 | 不改夹口/胶带锚点与布局；纸面可连同文字、数字整体微量轻抬，但不改变纸张轮廓或数据；不把装饰互动当成数据刷新 |

层序固定为：**天幕 → 月轮/星空 → 云雾与降水 → 不透明纸面 → 局部纸缘接触**。雷暴只给柔和受光，不自动频闪；夹端引雷为明确点击触发的一次局部样例，数据不闪。月位不做装饰漂移，月相由数据决定；月晕可慢呼吸。`new` 没有亮面/月晕，`below` 不把月轮显示在地平线上方。

当前交互锚点统一为：评分纸仅圈注 / 等级暖光；黄铜夹和单次闪电属于时间纸；风带、胶带尾与真实纸面的整体轻抬属于天气批注纸的阵风反馈。评分纸不放黄铜夹，时间纸不放风触发胶带。共享 `card-foundation.css` 定义纸、字、夹子和风接触的静态几何；天气运行时只对原纸面元素施加局部 transform，不生成独立卷角，不改纸笺材质、轮廓或布局。

场景650 ms是环境交叠，不应照搬到频繁点击、抽屉或按钮反馈。全局已有 `--duration-scene`、`--duration-cloud`、`--duration-moon`、`--duration-star` 由 tokens 统一提供，局部只引用，不声明根级 fallback。抽屉的240 ms和回弹280 ms属控件契约，不与环境时序互相替代。所有动画仅使用 transform/opacity；源稿 blur、SVG路径与插画色作为静态造型，不逐帧计算布局。

### 阵风的进入、路径与退出

WeatherStage风痕位于天空装饰层，始终在不透明纸面之后。`.sl-atmo-gust-band` 使用250×60 SVG，主弧、两条不同长度旁弧与少量错位复描组合为一组笔迹；`stroke-dasharray` 保留笔压断续，末端只局部回卷，不把整组风带旋转成碎屑。`.sl-atmo-gust-wisp` 使用较短的双弧；`.sl-atmo-gust-leaf` 使用不规则叶面、中脉和支脉，1.4 s `rotateY`翻面并缓慢滚转。路径和笔压均为静态图形，不逐帧改写SVG。

主带每批生成前读取控制区、标题和各纸笺的`getBoundingClientRect()`，换算为stage相对坐标，优先选择双纸上方最宽、上下留足32 px的天空通道；通道内横向行程按可用宽度计算，弯折限制在±2 px，避免主带长时间藏在纸后或掠过标题文字。风丝、叶片仍走普通纸后天空行程；不改变纸面层序来强行露出笔迹。

横向`linear`穿屏，纵向用`cubic-bezier(.77,0,.175,1)`弯折；近层2800 ms、峰值透明度.52，远层3600 ms、峰值.34且更短；旁线为主线一半透明度，复描.32。浅色天幕为薄铅笔灰绿，夜间暖白；14%渐入、末段22%淡出。分层依靠速度、透明度和长度，不堆满屏叶片，不用blur或闪光。所有运动仅使用transform / opacity；阵风时纸纹、文字、分数与时间只作为同一真实纸面的内容一起轻抬，不单独漂移或重排。

WeatherStage进入风天气160 ms后开始轻档，之后每7.2 s一批；胶带点击只发一批强档。0 ms前导、300 ms近主带、390 ms远主带（仅强档）、780 / 1000 ms短风丝（后者仅强档）、可选920 ms叶片、1400 ms余丝分阶段进入。轻档4–5载体、强档6–7；总上限18包含尚在等待的载体，重复点击只追加空余名额，旧一批仍完整淡出。纸面整体轻抬与胶带尾保持到5000 ms再自然回落，重复触发仅延长保持，不重置正在行进的笔迹。换天气 / 天色、关闭动效、系统减弱动态或页面隐藏时统一取消调度、回收及纸面反馈计时，并强制纸面`transform:none`；恢复不补播。

MotionFlow桌面 / 手机画板共用分层阵风方向：强档两组主带、轻档一组，轻5 / 强7载体，0 ms前导、300 / 380 ms主带、760 / 1050 ms伴丝、900 ms叶片与1400 ms余丝；近2800 / 远3600 ms。各载体独立到期释放，连续点击只使用空闲槽位，不重置或截断旧轮，最多18槽位。两稿继续支持天空右划 `dx > 90`、`abs(dy) < 55`、`dx > abs(dy) × 2`，移动超过12 px后500 ms抑制随后click，横笺区域不参与天空手势。

## 减弱动态与输入规则

- `prefers-reduced-motion: reduce`、本地动效关闭或页面隐藏：停掉所有粒子、风线、闪电/柔光变化、真实纸面轻抬、胶带尾、月晕及星光动画，强制纸面`transform:none`并去掉场景 transition；天气/天色立即切换，仍保留静态天气名称、云雾、月相、地平线下标记和雨雪雹纸缘识别。
- 不以微弱运动代替关闭：减弱动态时手动点击只给状态行文字，不闪光、不抬纸。系统设置实时改变时清理未完成效果。
- 键盘操作只抑制本次手动装饰反馈，不改变环境动效开关；环境阵风、雨雪和星光仍由天气、页面可见性及系统/用户动效设置决定。暂停或关闭后清理未完成效果，恢复时不补播积压动画。
- 手动装饰未播放时，辅助技术反馈明确写「动效已关闭」或「键盘操作仅文字反馈」，不宣称已起风、闪光或抬纸。**生产反馈仅提供给读屏（`aria-live` / visually-hidden），不在可视界面显示演示说明；设计预览保留可见状态，供演示输入、暂停与减弱动态边界。** 夜雨、夜风中的星光与普通星空遵循相同的缓慢闪烁规则；关闭动效时均停止。
- 月轮本体永远不平移。新月亮面退化路径保持原样；地平线下隐藏月轮、保留其相位资料。这不是天文计算替代品。
- 控件 >=44 px；选中使用朱砂笔迹，焦点使用墨色虚线。仅精细悬停指针启用 hover 装饰，触屏不依赖 hover。
- 强制颜色模式移除天空装饰/光晕/星点，使用 Canvas、CanvasText 与 Highlight 保留纸面、月相轮廓、选中下划线和焦点。天气文字不能被隐藏。

## 本地预览范围与静态限制

`WeatherStage` 提供9×4个可选环境组合、动效开关、650 ms交叠与三处纸面点击；使用 LetterStudy 的雨雪雹时序和当前阵风优化。风天气自动示范轻档，胶带点击示范强档；没有独立雨风强度控件或天空右划。日期按钮只改横笺选中态，固定主笺不联动；此限制在卡内可见，完整预报域由 Forecast 卡呈现。所有太阳/月轮坐标均固定的设计图示，非实时天文位置。

`MoonPhase` 的七种 selector 使用 MoonMobile 的原始亮面路径、坑纹裁切和 presets。日期只更新保留的预报上下文；不计算月龄、仰角、方位或农历。月晕12 s、透明度.5→.8，星光7 s、透明度.25→.55，均保留原稿时序。关闭/重开和返回应用路由不在本卡实现。

两个卡片都是原生 HTML/CSS/JS 参考，由共享 bundle.js 中的 SkyLetter 预览初始化函数驱动，不依赖框架、不安装生产行为适配层。主题初始跟随父级 day/dawn/dusk/night；手选天色后仅覆盖卡片环境，父级纸张/墨色主题仍生效。天气与月面基础色通过共享 tokens 消费；云雾、粒子、光晕与雨雪雹纸缘接触等源稿透明插画用色保留为插画几何用色，而非语义色。风下纸面反馈直接变换原纸面，不另画卷角。

上述时序和交互为代码 / 设计契约，不是本轮实机验收结果。本轮未运行浏览器、真实天气、设备能耗或减弱动态检查；源预览的具体行为边界见各组件 README，不能把静态图示或固定样例当作运行证明。
