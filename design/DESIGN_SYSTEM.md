## 1. 核心设计哲学与审美愿景

### 1.1 实体手札隐喻 (Physical Field Journal)
彻底告别冰冷、泛滥的科技暗色与玻璃拟态（Glassmorphism），回归有温度、有呼吸感的**“田野气象观测手记（Field Stationery Journal）”**。
- **世界观**：用户手持一本在原野与旷野中记录晨昏天色的气象学者手札。
- **实体材质**：米白和纸票据（Washi Paper Docket）、古典黄铜长尾夹（Brass Clip）、活页手撕齿孔条（Paper Perforations）、朱砂红检验印（Cinnabar Seal）、撕边和纸遮蔽胶带（Washi Masking Tape）与手工水彩试色条（Watercolor Swatch）。
- **自然背景**：背景不再是单调的 CSS 渐变，而是随真实经纬度与时间演变的**双层水彩天幕（Atmospheric Sky Canvas）**，页面实体卡片宛如平铺在浩瀚天色之上的观测记录纸。

### 1.2 核心任务与层级
1. **即时决策**：一目了然回答“下一场霞光值得等吗”。指数、事件时间（日出/日落）与行动建议在首屏拥有最高视觉重心。
2. **气象溯源**：随后展开云层分布（低/中/高云）、远端通透度、湿度与能见度等科学线索。
3. **真实感微互动**：让实体卡片与真实自然天气产生深度微物理共鸣，赋予工具深厚的人文与美学价值。
4. **零构建与极速交付**：保持原生纯静态架构，不引入臃肿框架与重型动画库，保证毫秒级直出。

### 2.1 材质规范细节
- **米白宣纸与圆点网格**：主手记卡片底色采用 `--paper-card-bg`，叠加 `radial-gradient` 呈现 16px 间距的复古点阵底纹，边缘辅以微小的自然倾角（`-0.35deg`）与内阴影漫反射。
- **黄铜长尾夹 (Brass Clip)**：采用双层金属渐变与高光线，位于主手记右上边缘（斜角 5deg）。带有立体夹痕压迹与物理倒影；在不同天气下呈现反光、积雪或火花。
- **手撕齿孔条 (Paper Perforations)**：卡片顶部排布均匀排列的齿孔痕迹，模拟从手记本撕下的活页质感。
- **朱砂印章 (Cinnabar Seal)**：方形双边框篆刻风印章，包含“验”、“测”或地点简字。具有细微的印泥墨渗感与倾角（`-4deg`）。
- **和纸遮蔽胶带 (Washi Tape)**：两端采用锯齿手撕边缘（`clip-path: polygon(...)`），半透明质感，透出底层纸张纤维纹理。
- **水彩试色条 (Watercolor Stroke)**：贯穿于卡片底部的有机色彩带，模拟气象水彩试色效果，颜色严格对应预报档位。

## 5. 组件与排版系统架构

### 5.1 主手记卡片 (Hero Master Card)
- **容器布局**：相对定位，上缘挂置黄铜长尾夹与手撕齿孔条。
- **信息层次**：
  - **Header**：当前观测地标（如“杭州 · 西湖观测点”）、时段胶囊（晨曦/暮光切换）。
  - **Body**：事件绝对时间（如“日落 18:14”）、核心大字号 0–99 霞光指数与评价标签。
  - **Footer**：朱砂篆刻印章、观测建议与水彩试色条。

### 5.2 未来 7 日预报卡片 (7-Day Forecast Cards)
为解决旧版高低不平、文字挤压换行的问题，7 日卡片统一采用**三行网格严格对齐结构 (Strict 3-Row Grid)**：
- **第一行 (Row 1)**：紧凑日期与星期（13px，字重 600，`line-height: 1.1`，冷灰米白基调，单行不折行）。
- **第二行 (Row 2)**：气象图形与天气简述（图标尺寸固定 22×22px，与文字严格垂直居中对齐）。
- **第三行 (Row 3)**：预报指数与分级刻度（`tabular-nums` 等宽大数字，分数字号 20px，右侧紧跟 10px 胶囊档位标签）。
- **视口适配**：桌面端（≥960px）采用 7 列并排实体票据展示；窄屏视口（<960px）采用原生惯性平滑横向滚动，带有视差渐隐边缘指示。

### 5.3 和纸票据弹窗与抽屉系统 (Stationery Docket Dialog & Sheet)
地点弹窗（`#places-dialog`）与开发者观测台（`#dev-lab-dialog`）全面手帐化：
- **和纸票据形态**：米白底色，四周 1px 细虚线边框，顶部加贴撕边和纸胶带装饰。
- **篆刻标题印章**：标头左侧并置朱砂红印章（如“地”字印、“记”字印）。
- **指南针罗盘卡片 (Compass Specimen)**：当前设备定位卡片采用深色仿皮革/金属罗盘设计，右上角配朱砂小印。
- **搜索输入与列表**：搜索框采用羊皮纸内阴影输入槽；搜索结果与收藏行采用点划线分隔，鼠标悬停带有向右滑动与朱砂红微变动效。
- **响应式抽屉断点 (760px)**：
  - **桌面端 (>760px)**：居中微倾角悬浮和纸票据卡，背景带温润天空磨砂遮罩。
  - **移动端 (≤760px)**：自适应为底部和纸抽屉（Bottom Docket Sheet），顶部露出实木质感拖动手柄（Drawer Handle），支持弹性阻尼跟手拖拽与滑动关闭。

## 6. 首屏渲染与 Zero-FOUC 抗闪烁规范

### 6.1 核心痛点与原则
**严禁冷启动白屏、严禁渲染瞬间露出旧深色或旧橙色背景**。用户点击打开应用的第一帧，视网膜感知到的必须是与当前时间吻合的纯净水彩天幕。

### 6.2 实现机制 (Synchronous Sky Hydration)
- 在 [index.html](../index.html) 的 `<head>` 底部注入极轻量同步水合脚本（零外部依赖，大小 < 1KB）。
- 脚本执行逻辑：
  1. 同步读取 `localStorage` 中上次缓存的经纬度、时区与当前天气主题。
  2. 根据当前时钟计算本地太阳仰角与晨昏状态。
  3. 首帧绘制前立即向 `document.documentElement` 写入天幕 CSS 变量与 `data-journal-ready="true"` 标记。
  4. 浏览器在解析 `<body>` 之前即完成水彩天幕着色，实现真正的 0 毫秒无缝水合。

## 7. 动效、可访问性与性能军规

遵循 Emil Kowalski 与 Apple Human Interface Guidelines 动效设计准则：

1. **严禁全局非特定 `transition: all`**：
   - 必须精确指定过渡属性（如 `transition: transform 200ms ease, opacity 200ms ease`）。
   - 彻底避免触发意外的几何重排（Reflow）与布局重算。
2. **复合图层与硬件加速**：
   - 动画属性严格限定于 `transform`、`opacity` 与 `filter`。
   - 关键物理元素开启 `will-change: transform` 或使用 `transform: translateZ(0)` 独立复合层。
3. **严格尊重减弱动态效果 (prefers-reduced-motion: reduce)**：
   - 当系统开启减少动效时：
     - 关闭双层 Canvas 中的所有落雪、降雨、飞叶与光子飘飞。
     - 禁用强风抖动、闪电电磁频闪与便签翻折。
     - 所有弹窗入场使用即时 `opacity` 切换，不包含长距离位移。
4. **悬停与触控解耦**：
   - 桌面手札悬停翘起效果严格限定在 `@media (hover: hover) and (pointer: fine)` 作用域内。
   - 移动端触控保留按压微凹（scale 0.98）的真实触觉反馈。

## 8. 自动化验证与质量门禁

每次变更必须通过以下验证流程方可合并或交付：

1. **代码检查与单元测试**：
   ```bash
   npm run verify
   ```
   - `npm run check`：确保所有 ES 模块无语法错误。
   - `npm test`：运行 `tests/` 下覆盖算法、气象映射、物理边界的 29 项单元测试。
2. **多端视口布局真实校验**：
   - 320px：极限窄屏无横向破框与孤字。
   - 390px / 430px：主流手机端底部抽屉流畅度与主卡片手撕纸边缘比例。
   - 760px：抽屉与桌面浮窗临界断点平滑切换。
   - 960px / 1200px+：未来 7 日卡片 7 列规整排版与等宽数字对齐。
3. **离线与缓存完整性**：
   - 每次样式或逻辑更新必须同步递增 `sw.js` 缓存版本号（如 `firecloud-shell-v53`）。
