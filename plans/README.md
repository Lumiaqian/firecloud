## Recommended Execution Order

```
[001: Lightning Sync] ──> [002: Zero-GC Rain] ──> [004: LERP Wind] ──> [003: Weather Decay]
```

1. **001 (Lightning Sync)**: Immediate high-visibility craft fix. Completely eliminates the glaring disconnect between lightning arcs and background sky exposure.
2. **002 (Zero-GC Rain)**: Critical runtime performance optimization. Cleans up hot-path allocations before layering on transition and smoothing states.
3. **004 (LERP Wind Dynamics)**: Enhances in-flight physics by smoothing wind vector changes with exponential decay interpolation.
4. **003 (Weather Decay Transition)**: Builds on top of the clean particle architecture to deliver smooth, cross-fading atmospheric shifts when changing cities or weather categories.

## Dependencies

- **001** and **002** are mutually independent and can be executed in parallel or any order.
- **004** should ideally precede **003** so in-flight physics smoothing is active during cross-weather state transitions.
